Abstract:
This paper describes a control framework for differential drive-wheeled mobile robots that autonomously manages position, heading, and speed using proximity and GPS sensor inputs. The system employs fuzzy logic algorithms to handle unmodeled dynamic environments. Key problems addressed include position estimation, path planning, and obstacle avoidance. Simulation results demonstrate successful autonomous navigation from arbitrary starting points to destinations without collisions.
